# Results policy

Generated experiment output belongs here locally and should not be committed unless it is small, reproducible, and accompanied by the exact config and data provenance.

The resume target `0.064` is a reference target only.

For a real-data result, record source, file names, normalization, event counts, fold boundaries, selected d, TDA backend, filtration parameters, CUDA device, Focal vs log-loss metrics, Pearson/Rank IC by fold, and aggregate mean/std.

Never commit proprietary or restricted raw market data.

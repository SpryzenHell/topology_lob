# Figures and run captures

The files in this directory are supporting evidence for the reproducibility documentation.

| File | Source | Use |
|---|---|---|
| `figures/lob_snapshot.svg` | Event 4,200 from the deterministic synthetic L2 generator | Shows the bid/ask depth geometry used to form a liquidity-support point cloud |
| `figures/betti_curves.svg` | Exact small-cloud VR calculation on the same generated L2 snapshot | Shows H0/H1 Betti counts across the configured radii |
| `figures/ffd_stationarity.svg` | Training-prefix ADF sweep from the deterministic synthetic generator | Shows the candidate fractional-differencing orders and the first candidate passing p < 0.05 |
| `figures/model_comparison.svg` | Measured current synthetic holdout run | Compares Pearson and Rank IC for Focal Loss and the log-loss control |
| `figures/cpp_benchmark.svg` | Measured standalone C++ benchmark | Records the local CPU throughput result |
| `screenshots/report_preview.svg` | Recorded run metrics | Compact preview of the generated run report |
| `screenshots/terminal_demo_run.svg` | Recorded run output | Terminal-style capture of the demo summary |

The synthetic figures are intentionally derived from deterministic data generated by the repository. They are not presented as historical market-data observations.

The two files in `screenshots/` are static run-output captures prepared for the README. They are not claims of a browser screenshot taken from a separate production application.

For a fresh execution, `run.py demo` generates the actual `metrics.json`, `test_scores.csv`, Betti plot, stationarity plot and `index.html` under the selected results directory.
